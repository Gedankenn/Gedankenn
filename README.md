Computer Engineer (UTFPR) shipping **firmware and Embedded Linux on production devices** in electronic security, railway and automotive. Today I'm **Systems Developer II at Control iD**, where I own production Embedded Linux images (**Yocto/BitBake, Device Tree, Linux kernel drivers**) and write bare-metal **C/C++** on three ARM Cortex-M families (**MSP, STM32, ESP32**): bootloader, OTA and board bring-up, plus cryptography, Ethernet/TCP-IP and MQTT.

I build low-level software where **physics, electrons and code collide**. My research roots are in motor control: Field-Oriented Control of BLDC/PMSM motors and Extended Kalman Filter state estimation. At home with oscilloscopes, logic analyzers, datasheets and a Linux terminal.
